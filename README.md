# Frontier Ashes — Mobile MVP

A small browser-playable prototype for the post-apocalyptic mobile shooter concept.

## Included in this MVP

- Landscape mobile-first canvas
- Virtual joystick movement
- Touch shoot button
- Optional keyboard controls for development
- Auto-targeting toward the nearest enemy
- Shooting, ammo and reload
- Dodge/invulnerability burst
- Enemy chase/combat
- Player health
- Pixel-art style rendering
- Small explorable wasteland
- Loot crates
- Inventory
- Basic HUD
- Pause panel
- Start screen

## Run

Open `index.html` in a modern browser.

For local development, any static server works, for example:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.
